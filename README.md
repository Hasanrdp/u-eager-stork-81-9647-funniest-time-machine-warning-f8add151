## The entry

`main.py` (Python 3.13, standard library only) writes one funny single-line
warning label for a time machine to `/output/entry.txt`:

> WARNING: Do not shake hands with yourself. The timeline is still deciding which one of you is real.

The label is fixed and deterministic: the program takes no input, uses no
network, and writes the same 99 bytes on every run. It is 99 characters,
inside the 1–120 character gate. The joke turns a real hazard of time travel
— meeting your duplicate self — into the punchline, keeps the straight face
of a genuine safety notice, and saves the surprise for the last few words.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
